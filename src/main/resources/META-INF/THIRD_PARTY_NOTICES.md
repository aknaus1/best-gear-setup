# Data attribution and distribution review

The repository's `LICENSE` describes the original plugin code as BSD-2-Clause. It does
not relicense external datasets or settle the licence of adaptations of upstream code.

Both `LICENSE` and this file are bundled in the plugin JAR as `META-INF/LICENSE` and
`META-INF/THIRD_PARTY_NOTICES.md` (copies under `src/main/resources/META-INF/`; a unit test fails
if they drift from the repository files), because the Plugin Hub distributes only the JAR.

## Wiki DPS calculator code

Formula references and adaptations are documented in `COMBAT_AUDIT.md`. The reference
repository, [weirdgloop/osrs-dps-calc](https://github.com/weirdgloop/osrs-dps-calc), publishes
[GPL version 3](https://github.com/weirdgloop/osrs-dps-calc/blob/main/LICENSE).
The audited reference revision is `89c3e25b344aea90d0189746e4b5f73dde0f0383`.

Game formulas and values are facts and are not themselves covered by copyright; the question is
whether any plugin *code* is an adaptation of the GPL-3.0 source. On 2 October 2026 the calculator code
(`src/main/java/com/bestgearsetup/calc`) was audited against all 33 library files of the reference
revision, and the close translations found were rewritten:

- Hit chance (`HitChance`): now counted exactly from the game's roll ranges, including negative rolls,
  following the Wiki's hit-chance, Osmumten's fang and confliction gauntlets pages, and checked against
  brute-force enumeration. (This also corrects the two-roll chance against a negative defence roll.)
- Dragon and burning claws specials (`SpecialDamage.claws`) and the burning claws burn
  (`SpecialDamage.burningClawDot`, now a closed form): rewritten from the weapons' Wiki pages.
- Theatre of Blood and Tombs of Amascut hitpoint scaling (`RaidScaling`): rewritten from the raids' Wiki pages.
- Chambers of Xeric scaling (`RaidScaling.cox`): restructured into the plugin's own form. Its values come from
  the reference because the Wiki does not publish them; they are credited in the source.

Audit method: `tools/reference_similarity.py` (structural token matching after normalising names and syntax,
plus comment comparison), followed by a manual side-by-side review of every calculator area against its
reference counterpart: accuracy and max-hit modifiers, magic and powered-staff max hits, spells, special
attacks, enchanted bolts, encounter damage rules, defence reductions, raid scaling and Vardorvis. No copied
comments were found. The remaining code shares the game's mechanics, constants and modifier order with the
reference but is written in the plugin's own structure (expected values rather than hit distributions,
combined accuracy/damage blocks, rule tables). This is an engineering review, not legal advice.

**Status: resolved.** The maintainer accepted this review on 2 October 2026. The plugin code is distributed
under the BSD-2-Clause licence; the reference calculator is credited above as the source of the Chambers of
Xeric values and as the formula reference audited in `COMBAT_AUDIT.md`. Re-run `tools/reference_similarity.py`
when calculator code changes.
